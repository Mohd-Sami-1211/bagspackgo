## How to prioritize once Search Console is available

1. Establish the current brand and provider-name query baseline.
2. Find nonbrand queries already receiving impressions and map them to the right page.
3. Prioritize terms that fit an available service and can lead to a useful booking or inquiry.
4. Review the actual results: intent, format, freshness, content depth and the evidence offered by ranking pages.
5. Expand a page when new questions support its purpose. Create a new page only for a distinct intent with enough original value.
6. Compare conversions and qualified inquiries before scaling content.
